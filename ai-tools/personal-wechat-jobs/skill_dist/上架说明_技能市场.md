## 六、干净电脑可用性（重点）

**「装完即用」已达成**，机制如下：

- 新机器第一条命令 `python scripts/bootstrap.py`：自动探测本机 python →
  在技能目录建**独立 venv**（`.venv`）→ 装 feedparser/requests/beautifulsoup4/lxml/PyYAML →
  校验导入 → 打印后续该用哪个解释器。**不污染用户系统环境**。
- 若系统 python 已具备依赖，bootstrap 秒过，直接用它。
- **不打包 `.venv`**（14MB 且与机器绑定），由 bootstrap 现场生成。
- 浏览器自动探测：`get_cookie.py --browser auto` 会找出本机 Edge/Chrome/Brave 逐个尝试，
  不再假设用户装了 Edge。
- 收件邮箱未配置时给出明确报错，不会静默失败。

> 唯一外部依赖是**网络**：pip 需要能访问 Python 包索引（用户已在用清华镜像）。
