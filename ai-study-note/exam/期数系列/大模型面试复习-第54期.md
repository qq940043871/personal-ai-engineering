### 1.2 InterpLab 模型可解释性平台（新旗舰）

**为什么需要它**：大模型是「黑盒」——出问题时只能看输入输出，无法回答「模型内部哪一层的哪个组件导致了幻觉/越狱/泄漏」。InterpLab 把研究界的 MI 工具工程化，落到生产排障与模型审计。

**六层架构**：

```
┌──────────────────────────────────────────────────────────────────┐
│  应用层 (Ops)    行为调试·红队·合规审计·能力盘点·特征级告警             │
├──────────────────────────────────────────────────────────────────┤
│  解释层 (Explanation)  LLM 自动标注特征语义 + 人工校准 + 特征卡片库    │
├──────────────────────────────────────────────────────────────────┤
│  监控层 (Capability Monitor)  危险特征哨兵(越狱/泄漏/欺骗方向)·实时拦截 │
├──────────────────────────────────────────────────────────────────┤
│  电路层 (Circuit)  归因图(Attribution Graph)·激活修补(Patching)·因果定位 │
├──────────────────────────────────────────────────────────────────┤
│  特征层 (Feature)  SAE 训练/推理·把叠加神经元拆成单义特征·特征字典管理   │
├──────────────────────────────────────────────────────────────────┤
│  采集层 (Harvesting)  Hooks 注入·按 layer/token 提取残差流激活·多后端  │
└──────────────────────────────────────────────────────────────────┘
```

**核心亮点速记**：
1. **特征单义化（SAE）**：用稀疏自编码器把 base model 的多义神经元拆成单义特征——Anthropic 在 Claude 3 Sonnet 同级模型上实测到 **3400 万特征/层**，并找到「金门大桥」「DNA」「代码注释」等语义纯净的特征。
2. **因果定位（Activation Patching）**：用 clean/corrupt 干预实验定位「是哪一层的哪个注意力头导致错误」，而非仅看相关性的归因分数。
3. **危险能力哨兵**：在 SAE 特征空间里定位「越狱模板/信息泄漏/欺骗」方向，做**内部意图级**实时监控，比关键词过滤本质。
4. **电路发现（Attribution Graph）**：把模型行为拆解成可解释的组件图，支持「为什么模型在这个问题上答对 / 答错」的可视化复盘。
5. **低成本落地**：实时只跑轻量探针（线性 probe）或采样 5% 步跑 SAE，永久排障才跑全量 SAE。

**量化成果（以 Claude 3 Sonnet 级模型为背景的示意平台）**：
- 单模型可解释特征：0 → **3400 万/层**
- 幻觉根因定位耗时：天级 → **分钟级**（特征级因果定位）
- 危险能力（越狱模板）检出率：弱监督 12% → **SAE 哨兵 91%**

## 二、技术难点（Technical Difficulties）

> 六大共性难点：①叠加假设 ②SAE 训练与死特征 ③激活修补因果归因 ④归纳头与 ICL ⑤线性表示与 steering 副作用 ⑥危险能力特征监控。均含根因 + 方案 + 代码/公式。

### 2.1 叠加假设 Superposition（为什么 d_model 能装下远超维度的特征）

**根因**：base model 的残差流维度是 d_model（如 4096），但模型掌握的语义特征远多于 4096 个。若每个特征占一个正交维度，容量被维度死死限制——可真实模型里神经元是多义的（一个神经元同时响应「猫」和「代码」），说明特征被**打包**了。

**本质（Elhage et al., 2022, Toy Models of Superposition）**：模型用**非正交基**在有限维度里容纳更多特征——只要两个特征「很少同时激活」，它们就能共用同一维度（方向略有夹角），激活值是二者在该维度上的投影之和，互不干扰的概率高。这是一种**用干扰换容量**的策略。

**数学**：
- 输入 $x = \sum_i a_i\, b_i$，$a_i\in\{0,\pm1\}$ 稀疏，$b_i$ 为单位方向（可非正交）
- 模型学字典 $D\in\mathbb{R}^{d_{model}\times d_{feature}}$，重建 $\hat{x}=D\,f$
- 损失含重建项 + 干扰项；当特征稀疏度 $s$ 高时，最优解让 $d_{feature} \gg d_{model}$
- **关键不等式**：若特征两两共现概率 $<\varepsilon$，则可在 $d_{model}$ 维里容纳约 $d_{model}/\varepsilon$ 个特征

**代码（玩具模型，实证 superposition 自发出现）**：
```python
import torch, torch.nn as nn

class ToySuperposition(nn.Module):
    def __init__(self, d_model=16, d_feature=64):
        super().__init__()
        D = torch.randn(d_model, d_feature)
        D = D / D.norm(dim=0, keepdim=True)   # 非正交字典（方向夹角≠90°）
        self.D = nn.Parameter(D)
        self.W = nn.Parameter(torch.randn(d_model, d_model) * 0.1)

    def forward(self, x):                      # x: [B, d_feature] 稀疏带符号
        true = self.D @ x.T                    # [d_model, B] 叠加后的“真实”激活
        recon = self.W @ true                  # 模型从激活重建
        return recon, true

def make_batch(B, d_feature, k=3):             # 每样本仅激活 k 个特征（稀疏）
    x = torch.zeros(B, d_feature)
    idx = torch.stack([torch.randperm(d_feature)[:k] for _ in range(B)])
    x.scatter_(1, idx, torch.rand(B, k) * 2 - 1)
    return x

model = ToySuperposition(); opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for _ in range(2000):
    x = make_batch(128, 64, k=3)
    recon, true = model(x)
    loss = ((recon - true.T)**2).mean()        # 仅重建损失
    opt.zero_grad(); loss.backward(); opt.step()
```
**现象**：k 很小（稀疏）时，学到的 $W$ 的列近似等于 $D$ 的伪逆，但 $D$ 用远多于 $d_{model}$ 的特征——这就是 superposition。

### 2.2 稀疏自编码器 SAE（把叠加拆回单义特征）

**根因**：base model 神经元多义，无法直接解释。需要一层「反叠加」变换。

**方案**：在某一层残差激活上训一个**过完备** SAE，强制隐层稀疏 → 每个隐单元更「单义」。

**数学 + 代码**：
- 编码器 $f=\mathrm{ReLU}\big(W_{enc}\,(x-b_{dec})+b_{enc}\big)$
- 解码器 $\hat{x}=W_{dec}\,f+b_{dec}$
- 损失 $L=\|x-\hat{x}\|_2^2+\lambda\,\|f\|_1$，$\lambda$ 控制稀疏度
- 训练技巧：① $W_{dec}$ 列单位归一（提升单义性）② dead feature 重采样（激活长期 < 阈值则重置）③ auxiliary loss（防死特征）

```python
class SAE(nn.Module):
    def __init__(self, d_in=4096, d_hidden=65536, l1=1e-3):
        super().__init__()
        self.W_enc = nn.Parameter(torch.randn(d_hidden, d_in) * 1e-3)
        self.b_enc = nn.Parameter(torch.zeros(d_hidden))
        self.W_dec = nn.Parameter(torch.randn(d_hidden, d_in))
        self.b_dec = nn.Parameter(torch.zeros(d_in))
        self.l1 = l1

    def forward(self, x):                        # x: 残差激活 [B, d_in]
        f = torch.relu(self.W_enc @ (x - self.b_dec).T + self.b_enc[:, None])
        x_hat = (self.W_dec @ f).T + self.b_dec
        recon = ((x_hat - x)**2).sum(-1).mean()
        sparse = self.l1 * f.abs().sum(0).mean()
        return x_hat, f.T, recon + sparse

    def unit_norm_(self):
        with torch.no_grad():
            self.W_dec.data /= self.W_dec.data.norm(dim=1, keepdim=True)
```
**为什么有效**：过完备 + L1 让模型倾向用「少量、方向近似正交」的特征组合重建，逼近 superposition 的反操作。Anthropic 在 Claude 3 Sonnet 上训出 **3400 万特征/层**，并找到单义特征。

### 2.3 激活修补 Activation Patching（因果归因）

**根因**：知道「哪层」不对，但不知道「哪个组件」导致错误（如幻觉）。传统归因（Integrated Gradients）是相关性，可能被饱和/基线选择误导。

**方案**：clean 输入正常跑、corrupt 输入破坏某信息跑；把 clean 在某组件（层/头/位置）的激活「补丁」到 corrupt 跑里，若输出恢复，则该组件**因果负责**。

**代码（组件级间接效应 Indirect Effect）**：
```python
def activation_patch(model, clean, corrupt, patch_pos, layer_idx, head_idx=None):
    clean_act = get_activation(model, clean, layer_idx, head_idx)   # [1, T, D]
    def hook(mod, inp, out):
        out[0, patch_pos] = clean_act[0, patch_pos]                # 注入 clean 激活
        return out
    with register_hook(model, layer_idx, hook):
        patched = model(corrupt).logits
    base = model(corrupt).logits
    ief = logit_diff(patched) - logit_diff(base)                   # 输出恢复量
    return ief
```
**应用**：定位「幻觉发生在第 L 层注意力头 H，因为它把 query 跨文档注意力错误放大」——比单纯归因分数更贴近「因果」。

### 2.4 归纳头 Induction Heads（in-context learning 的最小电路）

**根因**：few-shot 学习到底靠什么？Olsson et al., 2022 证明是**归纳头**两跳电路，而非某种神秘机制。

**电路**：
1. **previous-token head**（前层）：把 token 指向它前一个 token
2. **induction head**（后层）：当看到 "A B … A" 时，注意力跳到前一个 "A" 之后的位置 "B"，从而复制出 "B"

**代码（用注意力模式检测归纳头）**：
```python
def find_induction_head(attn):                  # attn: [L, H, T, T]
    best = None
    for l in range(attn.shape[0]):
        for h in range(attn.shape[1]):
            P = attn[l, h]
            # 归纳头特征：pos i 对“与 i 之前相同 token 的下一个位置”高权重
            score = induction_score(P)          # 见 Olsson 原文指标
            if best is None or score > best[2]:
                best = (l, h, score)
    return best
```
**意义**：解释了「模型没训练过也能 few-shot」，并揭示 Transformer 的「复制」先验——也是 RAG 检索错误会被放大的根因之一（induction 复制先验可能覆盖参数化知识）。

### 2.5 线性表示假说 Linear Representation Hypothesis（与 steering 副作用）

**根因**：概念在模型里怎么存？「国王 − 男人 + 女人 ≈ 女王」暗示概念是**线性方向**。

- 形式：对任意概念 $c$，存在单位向量 $v_c$，使 $\langle h, v_c\rangle$ 近似该概念在输入中的强度。
- 应用：用**线性探针**分类概念；用 **steering vector**（激活上加 $\alpha\cdot v_c$）控制生成（更诚实 / 更危险）。

```python
def steering_vector(acts_honest, acts_liar):
    return (acts_honest.mean(0) - acts_liar.mean(0)).normalize()
def apply_steer(h, v, alpha=3.0):
    return h + alpha * v
```
**风险**：线性只是近似，存在非线性 / 叠加干扰；steering 不当会触发其他特征（superposition 副作用），即「误伤」。

### 2.6 危险能力特征监控（特征级安全阀）

**根因**：传统 safety 评测只看输入输出，模型可在权重里「藏着」越狱/泄漏能力。

**方案**：在 SAE 特征空间里定位「危险方向」（deception / jailbreak-template / PII-leak 特征），实时哨兵：
- 推理时对每步残差流过 SAE，检测危险特征激活幅值 > 阈值 → 拦截/降级
- 比关键词过滤更本质：抓的是「模型内部意图方向」，不是表层词

**量化**：越狱模板特征在 Claude 级模型上检出率从弱监督 12% → **SAE 哨兵 91%**（示意）。

## 三、常见问答（Common Q&A）—— 6 道深度问题

### Q1：什么是 superposition？为什么 d_model 能表示远超其维度的特征？
**五层答案**：
1. **定义**：神经网络用**非正交基**在有限维度里打包更多特征——只要两特征很少同时激活，就能共用一维。
2. **为什么可能**：干扰成本正比于共现概率；稀疏场景下干扰可忽略，容量却翻数倍（约 $d_{model}/\varepsilon$ 个特征）。
3. **数学**：Toy Model 损失=重建+干扰；最优解在稀疏时选择叠加而非正交。
4. **证据**：base model 神经元多义（polysemantic），SAE 后才单义——反证叠加确实存在。
5. **面试加分**：区分「叠加」与「过拟合」——叠加是**主动的容量策略**，不是噪声。
**加分项**：能手写 toy model 训练循环（见 2.1），并指出「稀疏是叠加的前提」。

### Q2：SAE 相比 PCA / 传统 Autoencoder，解释性更好在哪？λ 怎么选？
**四层答案**：
1. **PCA**：正交、最多 $d_{model}$ 个成分、按方差排序——抓不到语义，且成分仍可能多义。
2. **AE（无稀疏）**：可过完备，但无稀疏约束 → 特征仍纠缠（entangled / polysemantic）。
3. **SAE**：过完备 + L1 → 稀疏 + 近似正交的 $W_{dec}$ 列 → 单义特征。
4. **λ 选择**：太小→多义；太大→死特征（dead）/ 重建崩。用 **dead-feature 比例**（目标 <1–10%）和 **L0 活跃数** 作指标做 sweep；配合 dead-feature 重采样。
**加分项**：知道 Anthropic 的规模化规律（特征数↑ → 单义性↑、死特征↓）与 jump-relu / top-k SAE 等改进。

### Q3：Activation Patching 与 Integrated Gradients 归因有何本质区别？
**三层答案**：
1. **IG**：沿基线到输入的路径积分梯度，是**相关性**归因；对基线选择敏感、遇饱和可能为 0。
2. **Patching**：**因果干预**——交换激活、直接测输出变化（Indirect Effect），回答「这个组件是否导致该行为」。
3. **互补**：IG 快速提假设，Patching 确认因果；二者都假设组件相对模块化（compositionality 效应会干扰）。
**加分项**：能指出 Patching 的变种（resample ablation、causal mediation、attribution patching 用梯度近似全量交换）。

### Q4：归纳头如何解释 in-context learning？和 RAG 检索错误放大什么关系？
**四层答案**：
1. **电路**：previous-token head + induction head 两跳，实现 "A B … A → B" 的复制。
2. **规模现象**：在训练中期**突现**（phase change），与 few-shot 能力提升同步。
3. **解释 ICL**：few-shot 不需更新权重，靠的是这种「上下文复制 / 模式匹配」先验。
4. **与 RAG 关系**：RAG 注入上下文后，若模型 induction 复制先验过强，会**过度复制检索文档中的错误片段** → 幻觉放大；也解释为何「仅从给定上下文作答」偶尔失效（复制先验压过参数化知识）。
**加分项**：能举「检索到错误实体被原样抄出」的故障实例。

### Q5：线性表示假说的局限？steering vector 为什么会「误伤」其他特征？
**三层答案**：
1. **局限**：线性是近似；很多概念是 superpositioned（非线性、共享维度），甚至是非线性流形。
2. **误伤根因**：若 $v_c$ 与其他特征方向不正交，加 $\alpha v_c$ 会同时沿相关特征方向偏移 → 副作用（如「诚实」向量也改了语气）。
3. **缓解**：① 在 SAE 特征空间（更隔离）而非原始方向空间 steering；② 仅作用于少数层/ token；③ 小 α + probe 验证。
**加分项**：知道 steering 不能无限增强（会在特征空间中撞到其他概念 / 进入 OOD 区域）。

### Q6：机制可解释性能落地到生产排障吗？举一例。
**四层答案（以「长上下文偶发幻觉」为例）**：
1. **采集**：收集失败 vs 通过轨迹的残差激活。
2. **特征定位**：跑 SAE，找仅在失败时激活的特征（如「跨文档注意力 / 干扰项」特征）。
3. **因果确认**：Activation Patching 逐层逐头定位首个因果组件（某层某头过注意跨文档）。
4. **修复**：加引用约束解码 / 调整该 head 贡献 / 改切分；耗时从天级→分钟级。
**加分项**：能接 LLMOps（第39期）做特征级实时哨兵，并提到 SAE 推理延迟的折中（采样/仅关键层）。

## 四、模拟面试（Mock Interview）—— 3 道深度题

> 说明：用户指令标题写「1 个模拟面试问题」，但需求 #4 明确「生成 3 个针对性的模拟面试问题」，故按 #4 生成 3 道（与近 16 期一致）。三题均不与历史 73 道重复（历史多为单项目设计 / 单指标故障，本期为「可解释性平台设计 / 特征级排障 / 7B 追平诚实度」新角度）。

### 模拟题 1：为某 70B 生产模型设计「行为可解释 + 危险能力监控」平台，要求实时、低成本、可解释。

**参考答案要点**：
- **架构（三层路径）**：
  1. **离线**：周期性按层训 SAE（仅关键层），产出特征字典与「危险特征白名单 + 阈值」。
  2. **在线轻量**：token 级拦截，先过**廉价风险门**（困惑度 / 熵 / 关键词），命中才跑 SAE；关键层跑**线性探针**（单次矩阵乘，<1ms）而非全量 SAE，仅采样 5% 步跑全 SAE 做根因。
  3. **告警 / 审计**：特征激活时间线 + 证据（哪个特征触发）+ 人工校准闭环。
- **成本工程**：全量 SAE 每 token 投影成本 ≈ $d_{hidden}$（65536 级）过高；折中 = 仅监控危险特征所在层 + probe 实时 + SAE 离线 / 抽样；批量解码摊薄。
- **延迟预算**：probe <1ms；SAE-on-sample <5ms（采样 5%）→ P99 影响可忽略。
- **权衡**：覆盖率 vs 成本；误拦（FP）vs 召回（越狱漏检）——用阈值 + 人工复核平衡。
- **加分**：把特征哨兵挂到 LLMOps Trace（第39期）实现「行为可观测」；提到 dead-feature 与概念漂移需定期重训 SAE。

### 模拟题 2：线上某 Agent 出现「偶发幻觉、且仅在长上下文触发」，30 分钟内定位根因并止血（用 patching + SAE）。

**参考答案要点**：
- **Triage（5min）**：构造最小复现（短 vs 长上下文对照），确认与上下文长度相关（非随机）。
- **假设（5min）**：注意力稀释 / induction 头跨文档过复制 / KV 污染（历史轮次）。
- **定位（15min）**：① 失败(长) vs 通过(短) 轨迹跑 SAE，找「仅长失败激活」特征（如「干扰项 / 跨文档」）；② Activation Patching 逐层→逐头定位首个因果组件（如第 L 层某 head 跨文档过注意）。
- **根因 + 修复（5min）**：典型根因=该 head 把 query 错误对齐到干扰文档实体；修复=加 chunk 级注意力掩码 / 重排 / steering 抑制该 head / 显式「仅从引用 span 作答」约束。
- **止血（即时）**：临时把长上下文流量路由到更保守 prompt（强制引用）/ 限制 context 窗口 / 回退 retrieve-then-answer；永久修复随下次发布上线。
- **收尾**：用 LLMOps（第39期）监控该特征激活率，防复发。
- **加分**：提到 superposition 导致该 head 同时编码多个概念，单纯改权重可能误伤，需用 SAE 特征级干预而非整头置零。

### 模拟题 3：如何用 SAE + steering 让一个开源 7B 模型在「诚实度」上追平 GPT-4 级，且不损害其他能力？

**参考答案要点**：
- **定位诚实特征**：① 构造对比数据（诚实 vs 欺骗回答）；② 找两类激活分离度最高的 SAE 特征（或用「truthful」线性探针定位方向，再映射到最近 SAE 特征）。
- **推理期 steering**：在相关层残差流加 $\alpha\cdot$ 特征方向（仅事实生成段，非创意段）。
- **保能力四板斧**：① 仅作用于少数层 / token；② 用 SAE 特征（隔离）而非原始方向 → 减少 bleed；③ 小 α + 验证；④ 以对比偏好数据（DPO 式）作补充，避免分布偏移。
- **评估**：TruthfulQA 看诚实度提升；MMLU / IFEval 看通用能力不退化；在 α–TruthfulQA–MMLU 的 Pareto 前沿上标定 α。
- **诚实声明**：steering 单独难完全追平 GPT-4 诚实度，需「数据（诚实 SFT/DPO）+ 推理期 steering 增强」组合；并提示 superposition 风险（特征不正交会误伤）。
- **加分**：提到 top-k / jump-relu SAE 比 ReLU SAE 特征更单义，steering 更干净。

## 五、速记卡（Cheat Sheet）

| 概念 | 一句话 | 关键公式 / 代码点 |
|---|---|---|
| **Superposition** | 非正交基打包，稀疏是前提 | 可容纳 ≈ $d_{model}/\varepsilon$ 个特征 |
| **SAE** | 过完备 + L1，解叠加，特征单义化 | $L=\|x-\hat{x}\|^2+\lambda\|f\|_1$，列归一 |
| **Activation Patching** | clean/corrupt 干预，测**因果**非相关 | $IEF=\Delta\text{logit\_diff}$ |
| **Induction Head** | previous-token + copy，few-shot 根基 | 两跳电路，训练中突现 |
| **Linear Repr** | 概念=方向，可 probe / steer | $v_c$：steering 加 $\alpha v_c$ |
| **危险哨兵** | 特征空间抓越狱/泄漏，比表层过滤本质 | 危险特征激活幅值 > 阈值拦截 |
| **落地** | 仅关键层 + probe 实时 + SAE 抽样 | 实时 <1ms，根因分钟级 |
