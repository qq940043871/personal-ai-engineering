数据集划分

完整的机器学习数据集通常分为三部分: ┌──────────────────────────────────────────────────────────────┐ │ 全部数据 │ ├─────────────────┬─────────────────┬──────────────────────────┤ │ 训练集 │ 验证集 │ 测试集 │ │ (Train Set) │ (Validation) │ (Test Set) │ │ 70-80% │ 10-15% │ 10-15% │ ├─────────────────┼─────────────────┼──────────────────────────┤ │ ✔ 训练模型 │ ✔ 调超参数 │ ✘ 不动它！ │ │ ✔ 学习特征 │ ✔ 选模型 │ ✔ 最终评估才用 │ └─────────────────┴─────────────────┴──────────────────────────┘

为什么需要验证集？ 如果直接在测试集上调参，会"泄露"信息。验证集就像"模拟考"，测试集才是"高考"。

核心指标

指标公式关注点
准确率 (Accuracy)(TP+TN)/(TP+TN+FP+FN)整体正确率
精确率 (Precision)TP/(TP+FP)查准率（宁缺毋滥）
召回率 (Recall)TP/(TP+FN)查全率（宁可错杀一千）
F1 Score2×P×R/(P+R)精确率与召回率的调和平均

高精确率场景：癌症筛查

宁愿说"没病"也不误诊 → 精确率优先

高召回率场景：疫情检测

宁愿误诊也不漏掉一个 → 召回率优先

过拟合与欠拟合

过拟合 (Overfitting)

  • 训练好、测试差
  • 模型过于复杂
  • 方案：正则化、更多数据、Dropout、早停、简化模型

欠拟合 (Underfitting)

  • 训练差、测试差
  • 模型太简单
  • 方案：更复杂模型、更多特征、减少正则化、更长时间训练

交叉验证 (Cross Validation)

K-Fold 交叉验证 (K=5): Fold 1: □□□□■ 验证 → 分数₁ Fold 2: □□□■□ 验证 → 分数₂ Fold 3: □□■□□ 验证 → 分数₃ Fold 4: □■□□□ 验证 → 分数₄ Fold 5: ■□□□□ 验证 → 分数₅ 最终分数 = 平均(分数₁, 分数₂, ..., 分数₅) 优点：更稳定、更充分利用数据 适用：数据量较小的时候特别有用
