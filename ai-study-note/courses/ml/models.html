1 线性模型

线性回归 (Linear Regression)

预测连续值:
    ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
    
损失函数 (MSE):
    Loss = (1/n) Σ(ŷᵢ - yᵢ)²

可视化:
    ↑ y
    │    ·  ·
    │   ·   ·  ·
    │  ·  ·    ·  ← 回归线: ŷ = wx + b
    │ · ·  ·    
    └───────────→ x

逻辑回归 (Logistic Regression)

分类问题，输出概率值:
    ŷ = σ(w·x + b)
    σ(z) = 1 / (1 + e⁻ᶻ)   ← Sigmoid 函数

输出解释:
    σ(z) ≥ 0.5 → 类别 1（正类）
    σ(z) < 0.5 → 类别 0（负类）

Sigmoid 曲线:
    ŷ
   1 ┤░░░░░░░░░░░░░░░░░░░░░░
    │         ░░░░░░░░░
   0.5 ┤──────×───────────   决策边界
    │  ░░░░░
   0 ┤░░
    └───────────────────→ z

2 树模型与集成学习

决策树 (Decision Tree)

决策过程就像一个 if-else 树:
                ┌─────────────┐
                │ 年龄 < 30?  │
                └──────┬──────┘
                       │
           ┌───────────┴───────────┐
           ▼                       ▼
    ┌─────────────┐         ┌─────────────┐
    │ 收入 > 50K? │         │ 有房产?     │
    └──────┬──────┘         └──────┬──────┘
           │                       │
       ┌───┴───┐               ┌───┴───┐
       ▼       ▼               ▼       ▼
    ┌─────┐ ┌─────┐         ┌─────┐ ┌─────┐
    │ 是  │ │ 否  │         │ 是  │ │ 否  │
    └─────┘ └─────┘         └─────┘ └─────┘

随机森林 (Random Forest)

┌─────────────────────────────────────────────────────┐
│ 随机森林 = 多棵决策树的投票结果                        │
│                                                       │
│  树1 ──→ 预测A                                       │
│  树2 ──→ 预测A  ──→ 多数投票 ──→ 最终预测: A         │
│  树3 ──→ 预测B                                       │
│  树4 ──→ 预测A                                       │
└─────────────────────────────────────────────────────┘

XGBoost / LightGBM / CatBoost

梯度提升树 (GBDT) 家族:
    XGBoost   ─→ 工业界最常用，Kaggle 竞赛常胜将军
    LightGBM  ─→ 训练更快，内存更少
    CatBoost  ─→ 原生支持类别特征

核心思想：串行训练，每棵新树纠正前一棵的错误

树模型对比

3 支持向量机 (SVM) 

SVM 核心思想：找到最优超平面，最大化分类间隔

                ↑
    ○ ○ ○      │      ● ● ●
    ○ ○ ○      │      ● ● ●
    ○ ○ ○    ══╪══    ● ● ●
               ╱│╲
              ╱ │ ╲     ← 支持向量 (Support Vectors)
             ╱  │  ╲
   类别 -1 ←────┼─────→ 类别 +1
                │
            最大间隔 (Max Margin)
特性 说明
核技巧 用 RBF/Poly 核将数据映射到高维空间，处理非线性问题
支持向量 只有少数样本决定决策边界，效率高
适用场景 小样本、高维数据、文本分类

4 其他经典算法

k-NN (k-Nearest Neighbors)

新样本的类别由最近的 k 个邻居决定:
    
    新样本? ──→ ●
    
    最近邻 (k=3):
    ┌─────────────────┐
    │ ○ ○              │
    │   ○  ●  □        │  → 2个○ + 1个□ → 预测为○
    │       □ □        │
    └─────────────────┘
    
    优点: 简单直观，无需训练
    缺点: 计算量大，维度灾难

k-Means 聚类

无监督聚类算法:
        初始中心        迭代更新        收敛结果
    ┌──────┐      ┌──────┐      ┌──────────┐
    │  ○   │      │  ○   │      │ ○○○      │
    │  ●   │  →   │○ ●  │  →  │ ○●  □□□   │
    │  □   │      │  □   │      │    □□     │
    └──────┘      └──────┘      └──────────┘
    
    流程:
    1. 随机选 k 个初始中心
    2. 每个点归到最近的中心
    3. 重新计算每个簇的中心
    4. 重复 2-3 直到收敛

PCA 降维 (Principal Component Analysis)

将高维数据投影到低维空间:
                   PC2
                   ↑
    原始数据       │  新坐标
    ┌──────┐    ┌──┴──────┐
    │  ··  │    │   ··    │
    │·  · ·│ →  │ ·  · ·  │ → 保留 PC1（最大方差方向）
    │ ··   │    │  ··     │
    └──────┘    └─────────┘
                   → PC1
    用途: 可视化、降噪、加速训练

算法选择指南

数据类型 任务类型 推荐算法
数值特征 回归 线性回归 / XGBoost
数值特征 分类 逻辑回归 / SVM / XGBoost
图像数据 分类/检测 CNN (深度学习方向)
文本数据 分类/聚类 SVM / Naive Bayes
高维稀疏 分类 SVM / 逻辑回归
无标签数据 聚类 k-Means / DBSCAN
超大样本 分类 LightGBM / 随机森林
