机器学习概述与基础

机器学习 (Machine Learning) 是 AI 的核心分支，让计算机从数据中自动学习规律和模式。

什么是机器学习？ 

┌─────────────────────────────────────────────────────────────────┐
│                     Machine Learning                            │
│                        机器学习                                  │
│                                                                 │
│  输入数据 ──→ 学习算法 ──→ 模型 ──→ 预测/决策                   │
│  (经验)        (训练)      (知识)     (推理)                    │
└─────────────────────────────────────────────────────────────────┘

核心思想：从数据中学习模式，无需显式编程规则。

传统编程 机器学习
数据 + 规则 → 答案 数据 + 答案 → 规则

主要类型

监督学习 (Supervised Learning) 

┌─────────────────────────────────────────────────────────────────┐
│ 监督学习: 使用标注数据训练，学习输入→输出映射                      │
│                                                                 │
│  训练样本: (图片, "猫") → 学习"什么是猫"                         │
│  任务类型: 分类（离散输出）/ 回归（连续输出）                     │
└─────────────────────────────────────────────────────────────────┘

无监督学习 (Unsupervised Learning) 

┌─────────────────────────────────────────────────────────────────┐
│ 无监督学习: 发现未标注数据中的隐藏结构                            │
│                                                                 │
│  输入: 一堆无标签的新闻文章                                       │
│  输出: 聚类成不同主题（体育、科技、娱乐...）                      │
└─────────────────────────────────────────────────────────────────┘

强化学习 (Reinforcement Learning) 

┌─────────────────────────────────────────────────────────────────┐
│ 强化学习: 智能体通过与环境交互学习最优策略                        │
│                                                                 │
│  智能体(Agent) ←→ 环境(Environment)                              │
│      ↓                ↓                                          │
│    采取动作     返回状态+奖励                                     │
└─────────────────────────────────────────────────────────────────┘

三种学习方式对比

类型 数据 目标 典型应用
监督学习 有标签 预测标签 图像分类、房价预测
无监督学习 无标签 发现结构 用户分群、降维可视化
强化学习 交互数据 最大化奖励 围棋AI、自动驾驶

基本术语

术语 英文 说明
特征 Feature 输入变量，描述数据属性
标签 Label 要预测的目标变量
模型 Model 输入到输出的映射函数
损失 Loss 预测与真实值之间的误差
训练 Training 从数据中学习参数的过程
推理 Inference 用模型对新数据进行预测
过拟合 Overfitting 训练好但泛化差
欠拟合 Underfitting 训练和测试效果都差

完整流程 

┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 数据收集  │──→│ 数据清洗  │──→│ 特征工程  │──→│ 模型训练  │──→│ 模型评估  │
│ & 采集    │   │ & 预处理  │   │ & 选择    │   │ & 调优    │   │ & 部署    │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
      │              │              │              │              │
      ▼              ▼              ▼              ▼              ▼
  原始数据       干净数据      特征矩阵       训练好的模型    生产环境

步骤详解

  1. 数据收集 — 从数据库、API、爬虫等渠道获取原始数据
  2. 数据清洗 — 处理缺失值、异常值、重复数据
  3. 特征工程 — 提取、转换、选择最有价值的特征
  4. 数据集划分 — 训练集 (70-80%) + 验证集 (10-15%) + 测试集 (10-15%)
  5. 模型选择 — 根据问题类型选择合适算法
  6. 模型训练 — 用训练数据学习参数
  7. 超参数调优 — 在验证集上调整模型超参数
  8. 模型评估 — 在测试集上评估最终性能
  9. 部署上线 — 将模型部署到生产环境

偏差-方差权衡 

                  欠拟合 ← 合适 → 过拟合
                  
高偏差 / 低方差         低偏差 / 高方差
   ▓▓▓▓▓▓▓░░░             ▓▓▓░░░░░░░
   训练误差高              训练误差低
   测试误差高              测试误差低（但测试高）
   
         ┌───────────────┐
         │  目标：平衡！  │
         └───────────────┘
问题 症状 解决方案
高偏差（欠拟合） 训练误差高 更复杂的模型、更多特征
高方差（过拟合） 训练好但测试差 正则化、更多数据、简化模型
