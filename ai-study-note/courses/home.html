学习路线建议

🟠

阶段 1：机器学习基础

  1. 1. 理解基本概念：特征、标签、模型、损失函数
  2. 2. 掌握三大类型：监督学习 / 无监督学习 / 强化学习
  3. 3. 学习经典算法：线性回归、SVM、决策树、k-Means
  4. 4. 学会评估方法：准确率、精确率、召回率、F1 Score
🔵

阶段 2：深度学习入门

  1. 1. 人工神经元与感知机
  2. 2. 激活函数：ReLU / Sigmoid / Tanh / Softmax
  3. 3. 反向传播与梯度下降
  4. 4. 经典架构：CNN（图像）/ RNN / LSTM（序列）
  5. 5. 优化器：SGD → Adam → RMSprop
🟣

阶段 3-4：Transformer 深入 & 大语言模型

  1. 1. 注意力机制：QKV 的由来与计算
  2. 2. 多头注意力：并行关注不同子空间
  3. 3. 编码器-解码器架构
  4. 4. 位置编码与残差连接
  5. 5. 预训练 / 监督微调 (SFT) / RLHF
  6. 6. 推理优化：KV Cache / Flash Attention / 量化
