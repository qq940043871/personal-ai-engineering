2 RNN 基础

RNN (Recurrent Neural Network) 通过隐藏状态在时间步之间传递信息。

RNN 展开视图: t=1 t=2 t=3 t=4 x₁ x₂ x₃ x₄ │ │ │ │ ▼ ▼ ▼ ▼ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ │RNN │──→│RNN │──→│RNN │──→│RNN │──→ ... └──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘ │ h₁ │ h₂ │ h₃ │ h₄ ▼ ▼ ▼ ▼ y₁ y₂ y₃ y₄ 核心公式: hₜ = tanh(Wₕ · [hₜ₋₁, xₜ] + bₕ) yₜ = Wᵧ · hₜ + bᵧ 其中: xₜ = 当前输入 hₜ₋₁ = 上一时刻的隐藏状态（记忆） hₜ = 当前隐藏状态 yₜ = 当前输出

3 RNN 的问题：梯度消失/爆炸

核心问题

当序列很长时，反向传播的梯度在链式求导中逐渐消失（趋近 0）或爆炸（趋近无穷）， 导致模型无法学习长距离依赖关系。

问题示例: "我出生在法国，...（中间 50 个词）... 所以我会说 ____" 简单 RNN 很难记住 50 步前的"法国"来预测"法语"！ 解决方案 → LSTM 和 GRU !

4 LSTM 长短期记忆网络

LSTM (Long Short-Term Memory) 通过三个门控机制 解决 RNN 的梯度消失问题。

LSTM 核心结构: 输入 xₜ ────────────────────────┐ 隐藏状态 hₜ₋₁ ──────────────────┤ 细胞状态 cₜ₋₁ ──────────────────┤ ▼ ┌─────────────────┐ │ 三个门控单元 │ │ │ 遗忘门: fₜ = σ(W_f·[hₜ₋₁, xₜ]) │ → 决定丢弃哪些旧记忆 │ │ │ 输入门: iₜ = σ(W_i·[hₜ₋₁, xₜ]) │ → 决定存储哪些新信息 │ │ │ 输出门: oₜ = σ(W_o·[hₜ₋₁, xₜ]) │ → 决定输出哪些信息 │ │ │ 候选值: čₜ = tanh(W_c·[hₜ₋₁, xₜ]) │ │ │ 更新细胞状态: │ cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ čₜ │ │ │ 更新隐藏状态: │ hₜ = oₜ ⊙ tanh(cₜ) │ └─────────────────┘

遗忘门

决定从细胞状态中丢弃什么信息。输出 0~1，0 表示完全忘记。

输入门

决定将什么新信息存入细胞状态。

输出门

决定当前时间步的输出是什么（基于细胞状态过滤）。

5 GRU 门控循环单元

GRU (Gated Recurrent Unit) 是 LSTM 的简化版本， 将遗忘门和输入门合并为一个更新门，减少了参数。

GRU 核心结构: 重置门: rₜ = σ(W_r·[hₜ₋₁, xₜ]) → 控制忽略多少过去的记忆 更新门: zₜ = σ(W_z·[hₜ₋₁, xₜ]) → 控制保留多少旧状态，接受多少新状态 → 同时承担了 LSTM 遗忘门+输入门的功能 候选值: ňₜ = tanh(W_n·[rₜ ⊙ hₜ₋₁, xₜ]) 最终状态: hₜ = (1-zₜ) ⊙ hₜ₋₁ + zₜ ⊙ ňₜ └──保留旧记忆──┘ └──接受新信息──┘

6 三者对比总结

特性 Simple RNN LSTM GRU
门控数量 0 (tanh) 3 (遗忘/输入/输出) 2 (重置/更新)
细胞状态 无 (只有 hₜ) 有 cₜ + hₜ 无 (只有 hₜ)
参数数量 少 多 (LSTM 单元 4 个权重矩阵) 中等 (GRU 单元 3 个权重矩阵)
长距离依赖 差 优秀 优秀
训练速度 快 慢 较快
效果 (多数任务) 差 最好 (略优于 GRU) 好 (接近 LSTM)
发布时间 1986 1997 2014

选择建议：

  • · 数据量大、需要最佳效果 → LSTM
  • · 追求训练速度、数据量中等 → GRU
  • · 不推荐直接使用简单 RNN（除非仅用于教学理解）
  • · 现代 NLP 任务优先考虑 Transformer（可完全替代 RNN）
