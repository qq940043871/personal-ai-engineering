优化与正则化

训练神经网络不仅是让损失下降，更是让模型学会泛化！

1 优化器 (Optimizers)

梯度下降的演进

SGD (1986) ──→ Momentum ──→ AdaGrad ──→ RMSprop ──→ Adam (2014) ↓ ↓ ↓ ↓ ↓ 基础 加速 自适应 改进版 集大成者

各优化器对比

SGD (随机梯度下降) ┌─────────────────────────────────────────────────────────────────┐ │ W = W - η·∇L(W) │ │ │ │ 每次用一个样本更新，波动大但可能跳出局部最优 │ │ │ │ 缺点: 学习率难调，在峡谷区域震荡 │ └─────────────────────────────────────────────────────────────────┘
Momentum (动量) ┌─────────────────────────────────────────────────────────────────┐ │ v = γ·v + η·∇L(W) │ │ W = W - v │ │ │ │ 保留历史梯度方向，加速收敛，抑制震荡 │ │ │ │ 想像一个小球从山坡滚下：速度会越来越快！ │ └─────────────────────────────────────────────────────────────────┘
Adam (自适应矩估计) ┌─────────────────────────────────────────────────────────────────┐ │ 自适应学习率 + 动量 = Adam │ │ │ │ 特点: │ │ ✅ 每个参数有自己的学习率 │ │ ✅ 适合大规模数据和参数 │ │ ✅ 默认超参数通常效果不错 │ │ ✅ 目前最常用的优化器！ │ └─────────────────────────────────────────────────────────────────┘

优化器选择

优化器 特点 适用场景
SGD 简单，需手动调学习率 小数据量，研究实验
SGD + Momentum 加速收敛，抑制震荡 图像分类等经典任务
AdaGrad 自适应学习率 稀疏特征场景
RMSprop 解决 AdaGrad 学习率衰减问题 RNN / LSTM
Adam 最常用，默认首选 大多数情况！
AdamW Adam + 权重衰减解耦 Transformer 训练

2 正则化技术 (Regularization)

防止过拟合的核心方法

L1/L2 正则化 ┌─────────────────────────────────────────────────────────────────┐ │ 在损失函数中加入权重惩罚项，限制模型复杂度 │ │ │ │ L1 (Lasso): Loss' = Loss + λΣ|wᵢ| → 产生稀疏权重 │ │ L2 (Ridge): Loss' = Loss + λΣwᵢ² → 权重趋向均匀 │ │ │ │ λ 是正则化强度，越大→惩罚越重→模型越简单 │ └─────────────────────────────────────────────────────────────────┘
Dropout ┌─────────────────────────────────────────────────────────────────┐ │ 训练时随机"丢弃"部分神经元，防止过拟合 │ │ │ │ 训练时: 测试时: │ │ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ │ │ │ ○ │ │ ○ │ │ ○ │ │ ○ │ │ │ │ × ○│ │○ × │ → │ ○ ○│ │○ ○ │ ← 所有神经元│ │ │ ○ × │ │ ○ │ │ ○ │ │ ○ │ 乘以(1-p) │ │ └─────┘ └─────┘ └─────┘ └─────┘ │ │ × = 被丢弃 (概率 p) │ │ │ │ 效果: 类似集成学习，防止神经元共适应 │ └─────────────────────────────────────────────────────────────────┘
Batch Normalization (批归一化) ┌─────────────────────────────────────────────────────────────────┐ │ 对每一层的激活值进行归一化 │ │ │ │ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ │ │ 层输入 │──→│ 归一化 │──→│ 缩放+偏移 │──→ 输出 │ │ │ │ │ μ, σ² │ │ γ, β │ │ │ └──────────┘ └──────────┘ └──────────┘ │ │ │ │ 好处: │ │ ✅ 加速训练（允许更大学习率） │ │ ✅ 减少对初始化的依赖 │ │ ✅ 轻微正则化效果 │ └─────────────────────────────────────────────────────────────────┘
早停 (Early Stopping) ┌─────────────────────────────────────────────────────────────────┐ │ 当验证集性能不再提升时提前停止训练 │ │ │ │ Loss │ │ ░░░░░░░░░░░░░░░░░ 训练曲线 │ │ ░░ ░░░░░░░░░░░░░░░░░ │ │ ░░ ░░░░░░░░░░░░ 验证曲线 │ │ ░░ ░░░░ │ │ └──────────────────────→ Epoch │ │ ↑ │ │ 此处停止！ │ └─────────────────────────────────────────────────────────────────┘
数据增强 (Data Augmentation) ┌─────────────────────────────────────────────────────────────────┐ │ 通过对训练数据做变换生成更多样本，这是最有效的正则化！ │ │ │ │ 图像数据: 文本数据: │ │ ┌──┐ ┌──┐ ┌──┐ ┌──┐ 同义词替换 │ │ │原│ │翻│ │旋│ │裁│ 随机插入 │ │ │图│ │转│ │转│ │剪│ 随机交换 │ │ └──┘ └──┘ └──┘ └──┘ 随机删除 │ └─────────────────────────────────────────────────────────────────┘

正则化方法总结

方法 原理 效果 适用场景
L1/L2 权重惩罚 限制模型复杂度 所有模型
Dropout 随机丢弃 防止共适应 全连接层
Batch Norm 归一化激活 加速训练 CNN/MLP
Layer Norm 层归一化 稳定训练 Transformer
早停 提前停止 防止过拟合 所有训练
数据增强 扩充数据 泛化最强 CNN/图像

3 学习率调度 (Learning Rate Scheduler)

学习率是训练中最重要的超参数！ 太大 → 震荡不收敛 太小 → 收敛太慢 合适 → 快速稳定收敛 最佳策略: 开始时大，逐渐减小

常见的调度策略

Step Decay (阶梯衰减): η │ │ ████ │ ████ │ ████ │ ████ └──────────────────→ epoch Cosine Annealing (余弦退火): η │ ████████ │ ██ ████ │ █ ████ │ █ ████ └──────────────────────→ epoch Reduce on Plateau (自适应): η │ ████████████ │ ████████ │ ████████ └──────────────────────────────→ epoch 验证损失不再下降时，学习率减半
调度器 策略 适用场景
Step Decay 每隔固定轮次减半 经典 CNN 训练
Cosine Annealing 余弦函数平滑下降 Transformer 训练
Reduce on Plateau 根据验证损失自适应 通用
Warmup + Decay 先升后降的热身策略 大模型训练

实践建议

新手训练神经网络的最佳实践: 1️⃣ 先用小数据集过拟合一个批次（确认模型能学习） 2️⃣ 选择合适的优化器: ┌───────────────────────────────────────┐ │ 默认选择: Adam (lr=3e-4) │ │ 如果数据量很大: SGD + Momentum │ └───────────────────────────────────────┘ 3️⃣ 加入正则化: ┌───────────────────────────────────────┐ │ 全连接层 -> Dropout(p=0.5) │ │ 卷积层 -> Batch Norm │ │ Transformer -> Layer Norm │ └───────────────────────────────────────┘ 4️⃣ 学习率调度: ┌───────────────────────────────────────┐ │ 先用 Cosine Annealing │ │ 如果不好用换 Reduce on Plateau │ └───────────────────────────────────────┘ 5️⃣ 监控训练: ┌───────────────────────────────────────┐ │ 训练损失 ↓ 验证损失 ↓ → 正常训练 │ │ 训练损失 ↓ 验证损失 ↑ → 过拟合！ │ │ 训练损失 ↑ 验证损失 ↑ → 学习率太大 │ └───────────────────────────────────────┘
