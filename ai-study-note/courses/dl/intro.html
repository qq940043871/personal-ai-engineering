神经网络基础

神经网络是深度学习的基石，灵感来源于人脑的神经元结构。

生物神经元 vs 人工神经元

生物神经元: 人工神经元: ┌──────────────┐ ┌──────────────────┐ │ 树突 ──→ │ │ x₁ ──w₁── │ │ 细胞体 ──→ │ │ x₂ ──w₂── Σ → σ → 输出 │ 轴突 ──→ │ │ ... +b │ │ 突触 │ │ xₙ ──wₙ── │ └──────────────┘ └──────────────────┘

数学表达

线性组合: z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b 激活输出: a = σ(z) 其中: wᵢ = 权重 (Weight) — 连接强度 xᵢ = 输入 (Input) — 特征值 b = 偏置 (Bias) — 阈值偏移 σ = 激活函数 (Activation Function)

激活函数

为什么需要激活函数？—— 引入非线性！

如果没有激活函数: 多层线性 = 一层线性 (表达能力有限) ŷ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W'x + b' ❌ 无论叠加多少层，仍然只是线性变换！ 有了非线性激活函数: ✅ 可以拟合任意复杂函数（万能近似定理）

反向传播 (Backpropagation)

核心思想

反向传播 = 链式法则 + 梯度下降 前向传播 (Forward) ┌───────────────────────────────┐ │ ▼ 输入 → 层1 → 层2 → ... → 输出 → 计算损失 ↑ │ └───────────────────────────────┘ 反向传播 (Backward)

四步训练过程

Step 1: 前向传播 ┌─────────────────────────────────────────────────────────────────┐ │ 输入数据通过网络从输入层传到输出层，计算预测值 │ │ │ │ x → h₁ = σ(W₁x + b₁) → h₂ = σ(W₂h₁ + b₂) → ŷ = W₃h₂ + b₃ │ └─────────────────────────────────────────────────────────────────┘
Step 2: 计算损失 ┌─────────────────────────────────────────────────────────────────┐ │ 计算预测值 ŷ 与真实值 y 之间的差距 │ │ │ │ Loss = (ŷ - y)² （回归任务） │ │ Loss = -[y·log(ŷ) + (1-y)·log(1-ŷ)] （分类任务） │ └─────────────────────────────────────────────────────────────────┘
Step 3: 反向传播梯度 ┌─────────────────────────────────────────────────────────────────┐ │ 从输出层开始，逐层计算每个参数的梯度（链式法则） │ │ │ │ ∂Loss/∂W₃ = ∂Loss/∂ŷ · ∂ŷ/∂W₃ │ │ ∂Loss/∂W₂ = ∂Loss/∂ŷ · ∂ŷ/∂h₂ · ∂h₂/∂W₂ │ │ ∂Loss/∂W₁ = ∂Loss/∂ŷ · ∂ŷ/∂h₂ · ∂h₂/∂h₁ · ∂h₁/∂W₁ │ └─────────────────────────────────────────────────────────────────┘
Step 4: 更新权重 ┌─────────────────────────────────────────────────────────────────┐ │ 沿梯度反方向更新参数，减小损失 │ │ │ │ W_new = W_old - η · ∂Loss/∂W_old │ │ （η = 学习率 Learning Rate） │ └─────────────────────────────────────────────────────────────────┘

梯度消失与梯度爆炸

使用 Sigmoid 时的梯度问题: 梯度消失 (Vanishing): 深层网络的梯度越来越小 → 前层几乎不学习 层1 层2 层3 层4 σ'≈0.2 σ'≈0.2 σ'≈0.2 σ'≈0.2 ↓ ↓ ↓ ↓ g₁ = g₄ × 0.2³ ← ｜← ｜← g₄ → 梯度几乎为0！ 解决方案: ✅ 使用 ReLU 激活函数 (梯度恒为 0 或 1) ✅ 残差连接 (ResNet) ✅ Batch Normalization ✅ 更好的初始化方法 (He / Xavier)
