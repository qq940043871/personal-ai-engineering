经典神经网络架构

从 CNN 到 RNN，掌握深度学习最常用的网络结构。

1 CNN (卷积神经网络)

专门处理网格型数据：图像、视频、时间序列

核心组件

输入图像 卷积层 池化层 ┌────────┐ ┌──────────────┐ ┌──────────┐ │ │ 卷积核 │ 特征图 │ 下采样 │ │ │ 图像 │ ────→ │ ▓▓ ░░ ▓▓ │ ────→ │ ▓▓ ░░ │ │ │ 滑动窗口 │ ░░ ▓▓ ░░ │ MaxPool │ ░░ ▓▓ │ └────────┘ └──────────────┘ └──────────┘ 3通道(RGB) 多层特征 尺寸减半

各层作用

卷积层 (Convolution Layer): ┌─────────────────────────────────────────────────────────┐ │ 用可学习的滤波器（卷积核）在图像上滑动，提取局部特征 │ │ │ │ 输入: 32×32×3 卷积核: 3×3×3 输出: 特征图 │ │ (高度×宽度×通道) (高度×宽度×输入通道) │ └─────────────────────────────────────────────────────────┘
池化层 (Pooling Layer): ┌─────────────────────────────────────────────────────────┐ │ 降采样，减小特征图尺寸，增加平移不变性 │ │ │ │ Max Pooling (2×2, stride=2): │ │ ┌───┬───┐ ┌───┐ │ │ │ 3 │ 1 │ │ 3 │ ← 取窗口内最大值 │ │ ├───┼───┤ → └───┘ │ │ │ 2 │ 4 │ │ │ └───┴───┘ │ └─────────────────────────────────────────────────────────┘
全连接层 (Fully Connected Layer): ┌─────────────────────────────────────────────────────────┐ │ 将提取的特征展平，进行最终分类 │ │ 输入: 特征向量 → 隐藏层 → 输出: 类别概率 │ └─────────────────────────────────────────────────────────┘

经典 CNN 架构演进

LeNet (1998) ──→ AlexNet (2012) ──→ VGG (2014) ──→ ResNet (2015) ↓ ↓ ↓ ↓ 手写数字 ImageNet突破 加深网络 残差连接 识别 GPU加速 统一3×3卷积 解决退化

网络对比

架构 年份 层数 特点

2 RNN / LSTM / GRU

处理序列数据：文本、语音、时间序列

RNN (循环神经网络)

RNN 的核心：循环连接 → 记忆 展开前: 展开后: ┌─────┐ ┌───┐ ┌───┐ ┌───┐ │ │ │h₀│→│h₁│→│h₂│→ ... │ ↗ │ = └───┘ └───┘ └───┘ │ ↻ │ ↑ ↑ ↑ └─────┘ x₀ x₁ x₂ 公式: hₜ = tanh(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + bₕ) 问题: 长程依赖 → 梯度消失 → 记不住太久远的信息

LSTM (长短期记忆网络)

LSTM 用"门控机制"解决 RNN 的长程依赖问题: ┌─────────────────────┐ │ LSTM 细胞 │ │ │ hₜ₋₁ ──────┬──────┤ ┌──────────┐ ├──────→ hₜ │ │ │ 遗忘门 │ │ xₜ ──┬─────┤ │ └──────────┘ │ │ │ │ ┌──────────┐ │ │ ├──────┤ │ 输入门 │ │ │ │ │ └──────────┘ │ │ │ │ ┌──────────┐ │ │ └──────┤ │ 输出门 │ │ │ │ └──────────┘ │ │ │ │ │ └─────────────────────┘

三门的作用：

门 作用 类比
遗忘门 决定丢弃哪些旧信息 删除旧的记忆
输入门 决定存储哪些新信息 写入新的记忆
输出门 决定输出哪些信息 读取记忆输出
遗忘门示例（语言模型预测下一词）: 输入: "我住在北京，我的____" 遗忘门: 丢弃"住"的具体信息，保留"地点"的上下文 输入门: 学习到模板是"我的[关系/所属]" 输出门: 预测"家" → "我的家"

GRU (门控循环单元)

GRU = LSTM 的简化版（只有两个门）: ┌─────────────────────────────────┐ │ GRU 细胞 │ │ │ │ hₜ₋₁ ───┬──────┬───── │ │ │ │ │ │ ↓ ↓ │ │ ┌──────┐ ┌──────┐ │ │ │更新门│ │重置门│ │ │ └──────┘ └──────┘ │ │ │ │ │ │ └──┬───┘ │ │ ↓ │ │ ┌──────┐ │ │ │ 候选h │ │ │ └──────┘ │ │ │ │ │ ↓ │ │ hₜ ────────┘ │ └─────────────────────────────────┘ 参数更少 → 训练更快 → 效果与 LSTM 相近

架构选择指南

任务类型 推荐架构 理由
图像分类 CNN / ResNet 局部特征提取能力强
目标检测 CNN (YOLO/SSD) 同时定位和分类
文本分类 Transformer / LSTM 捕获序列依赖
机器翻译 Transformer 并行计算，效果好
时间序列预测 LSTM / GRU 处理时间依赖
语音识别 RNN / Transformer 处理变长序列
