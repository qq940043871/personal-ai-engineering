来源三档 —— 人工编写：按语料出的题，带标准答案关键词； 问答日志回流：线上真实提问，踩坑/高频题优先； 直击库回归：L0/L1/L2 快问快答，该问题必须命中直击库，掉到检索链路即坏。
好坏判定 —— 人工题有期望词：TopN 候选必须含全部期望词且闸门一通过 → 好； 应拒答题：闸门一必须拦下 → 好（放行即坏）； 无期望词：只观察不判定（保持"待判"）——没有标准答案时给通过就是自欺， 点行内「设期望」或「标拒答」把题变成可判的。判定每次落库，也可人工改判。
题型分桶 —— 事实 / 概念 / 对比 / 排障 / 找全 / 跨文档 / 拒答 / 直击库。 只看总分会掩盖"事实题全过、跨文档全挂"这类结构性缺陷，所以分母必须拆开看。
