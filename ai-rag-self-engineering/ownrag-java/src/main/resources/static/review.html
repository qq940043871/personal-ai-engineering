解析复核

入库前的第三道闸：把原文档、解析后、清洗后三栏并排摊开，再加上切分结果，点「通过并入库」才真正写索引。 三栏是一条因果链——原文档长什么样、解析器还原成了什么、清洗又删了什么（清洗后的正文才是切分与入库的输入）。 自动检查只报事实（阻断项 / 提示项），放不放行由人决定——解析错了，后面检索与生成全错，而这件事在问答阶段查不出来。
